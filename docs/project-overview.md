# Project Overview

## Project name
TOONFlow for MariaDB

## Team
ClearQuery (MONASH)

## Summary
TOONFlow is a JSON-to-TOON ingestion layer for MariaDB that helps teams adopt TOON without abandoning existing JSON-based application flows. Incoming JSON is validated, converted to TOON, and stored alongside extracted fields that remain easy to query with SQL.

## Why this project matters
The project aims to make AI-ready data preparation more efficient while preserving standard database usability. Instead of treating TOON as a niche format, TOONFlow positions it as a practical extension to existing JSON workflows.

## Judge-facing story
This is not a generic TOON showcase. It is a low-friction adoption path for existing JSON pipelines, backed by measurable benchmarks and a simple evaluator-friendly demo.

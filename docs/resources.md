## How these resources shaped TOONFlow
- MariaDB JSON documentation informed the decision to store original JSON and extracted query fields explicitly.
- MariaDB Connector/Python documentation informed the optional live MariaDB repository path.
- TOON references informed the compact JSON-to-TOON representation and benchmark comparison.
- FastAPI and Streamlit documentation informed the API service and evaluator-facing demo layers.
